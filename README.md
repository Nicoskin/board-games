# Настольные игры: счёт и правила

Один статический сайт с двумя вкладками. Ставится на телефон как приложение и работает без интернета.

**Подсчёт очков** (`score/`)

- 7 чудес: Дуэль — `score/7-wonders-duel/`
- Агрикола (издание 2016) — `score/agricola/`
- Великий Западный Путь (2-е издание) — `score/great-western-trail/`
- Звёздные империи, счётчик влияния — `score/star-realms/`
- Каскадия — `score/cascadia/`
- Орлеан — `score/orleans/`

**Правила** (`rules/`)

- 7 чудес: Дуэль — `rules/7-wonders-duel.html`
- Замки Бургундии со всеми дополнениями — `rules/castles-of-burgundy.html`
- Каскадия — `rules/cascadia.html`

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него всё содержимое этой папки.
2. **Settings → Pages → Build and deployment**: Source — «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на телефон

Откройте сайт в браузере и выберите «Установить приложение» или «Добавить на главный экран».

Счётчики сохраняются для офлайна сами при первом открытии. Правила содержат сотни картинок из буклетов (около 32 МБ), поэтому они сохраняются по кнопке **«Сохранить для офлайна»** на вкладке «Правила» либо постепенно, по мере чтения.

## Как устроено

- `index.html` — главная с вкладками; список игр прописан прямо в разметке.
- `manifest.webmanifest`, `icons/` — описание и иконки приложения.
- `sw.js` — общий service worker. Список `ASSETS` — то, что кладётся в кэш при установке.
- Каждый счётчик — самостоятельная страница в своей папке; стрелка в шапке возвращает на главную.

Чтобы добавить игру: положите её в `score/<имя>/` или `rules/`, допишите карточку в `index.html`, файлы в `ASSETS` в `sw.js` и поднимите там `VERSION`. Для новых правил ещё добавьте имя страницы в список `RULES` в `index.html`, чтобы их сохраняла кнопка офлайна.

## Локальный просмотр

```bash
python -m http.server 8817
```

Затем откройте http://localhost:8817
